
# Typed validation-contract compiler for engineering AI

This repository is the public, hash-bound reproducibility package for
*Compiling deployment claims into auditable validation decisions for
engineering artificial intelligence*.

Repository release **2.0.0** contains the frozen compiler package **0.4.0**,
the complete aggregate-only Attempt-T evidence, the headed-stud application
projection, deterministic figure builders, tests, environment locks and
public-data acquisition records.  Attempt T is the sole admissible execution;
Attempts A--S are excluded and were not compared or used for scientific
selection.  The public receipt records all 38 completed stages and the
retain-all, no-favourable-selection gate.

## What the package does

The software compiles a typed deployment claim into a validation contract,
checks whether an assignment and its evidence satisfy that contract, and
returns one of several explicit states: exact execution, lossy execution,
certified refusal, unresolved search or invalid evidence.  It is designed to
make validation semantics auditable; it does not claim that semantic exactness
must lower prediction error.

## Quick verification

```bash
python -m pytest tests -q
python tools/audit_public_package_attempt_t.py .
```

The path-neutral public tests exercise the released compiler and figure gates.
The standalone audit checks the exact release receipt, all stage projections,
the Attempt-T closure and retention receipts, the primary-evidence lock, the
headed-stud projection and the full SHA-256 ledger.
