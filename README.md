# Validation-target mismatch in structural machine learning

## Package title
**Structural ML-Bench v1.0: Source-aware validation suite for structural performance prediction**

## Target manuscript
Computer-Aided Civil and Infrastructure Engineering (CACE) submission reproducibility archive.

## Summary
This repository contains scripts, manifests, processed outputs and figure-source data for a **source-aware validation framework** evaluating validation-target mismatch in structural machine learning (random vs grouped / deployment-matched cross-validation, topology diagnostics, and reporting checklist artefacts).

## What is included
- Source-aware validation protocol (SAVP) scripts and nine public reproduction drivers
- Machine-readable **Table S7** export: `outputs/tables/cace_ninemodule_rf_summary.csv` (when regenerated)
- **Table S8** topology master: `outputs/tables/table_s8_group_topology_master.csv`
- Figure-source CSVs under `outputs/figures_source/`
- OpenAlex / manual verification snapshots under `outputs/reproductions_literature_snapshot/` (when present in source tree)
- Reporting checklist data (`manuscript/` copies)

## What is **not** included
- Raw third-party data where redistribution is not permitted (see `data_manifests/dataset_manifest.csv`)
- Private correspondence or non-public datasets
- Any numeric claim not traceable to the bundled scripts/CSVs

## Quick start
```bash
conda env create -f environment_reproducibility_v0.yml
conda activate p1-structural-ml-validation
python tests/smoke_test.py
python code/run_qa_chain.py --skip-06 --skip-24   # if you already have results.csv
```

## Expected outputs (after full rerun)
- `outputs/tables/cace_ninemodule_rf_summary.csv`
- `outputs/tables/table_s8_group_topology_master.csv` (also generated by `build_release_package.py`)
- `figures/submission/` and `figures/supplementary/` raster/vector exports when scripts are run with data present
