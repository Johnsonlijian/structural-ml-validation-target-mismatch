
# Final release rights map

## Project-authored material

Project-authored source code and documentation in this repository are released
under the MIT License unless a file or directory contains a more specific
notice.

## Third-party source data

Raw third-party data are not redistributed.  `DATASETS_AND_LINKS.csv` and
`THIRD_PARTY_NOTICES.md` identify the authoritative records and licences.

## Aggregate application projection

The `app/` tree contains row-free aggregates and method metadata derived from
separately licensed sources.  CC BY 4.0 and CC BY-NC-SA 4.0 partitions remain
separated and their source-specific terms control redistribution and reuse.
The immutable application projection receipt records the licence state at the
time of its source audit; this final rights map supplies the later release
authorization for project-authored wrappers without overriding upstream terms.

## Exclusions

No licence is granted here for raw archives, reconstructed rows, active
manuscripts, correspondence, private records or any material not present in
the public file ledger.
