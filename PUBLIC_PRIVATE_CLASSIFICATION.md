# Public / private classification

| Category | Included | Notes |
|---|---|---|
| Audit and experiment scripts | yes | deterministic, fixed seeds |
| Identifier-resolution scripts | yes | `tools/network/`, no credentials stored |
| Configuration registry | yes | counts, relation semantics, declared-use status |
| Aggregate result tables | yes | metrics, fold structures, decision outcomes |
| Run receipts | yes | SHA-256 of third-party inputs, no content |
| Figures (vector + PNG) | yes | generated from aggregate tables |
| Per-row predictions | **no** | private audit record; redistribution rights not uniform |
| Raw third-party tables and workbooks | **no** | obtained by the user from public identifiers |
| Manuscript source, PDF, cover letter | **no** | active submission material |
| Internal rounds, logs, decision records | **no** | private project state |
| Credentials, tokens, private paths | **no** | scanned before commit |
