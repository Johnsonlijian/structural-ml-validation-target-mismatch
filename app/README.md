# Headed-stud public aggregate projection (public release)

This projection contains protocol metadata, hashes, contract-status records, and non-sensitive aggregate results only. It contains no downloaded archive, publication PDF, extracted record, canonical row table, row identifier, source-group identifier, prediction vector, target vector, or fold-assignment vector.

The projection is license-separated. Aggregates derived only from the three Mendeley parents are under `results/cc_by_4_0/`. Any aggregate containing the Zenodo RAC parent is under `results/cc_by_nc_sa_4_0/`. The project code/document license is still an author decision; this public release must not be published until that license and the final citation metadata are approved.
